# ちゅー勉！テストサイト

Canvaで作成した仮案を参考にした、PC・スマホ対応の静的サイトです。

## 内容
- `index.html`: ページ内容と簡単なスマホメニュー
- `style.css`: PC・スマホのレイアウトとデザイン

## 注意
- テキスト・問い合わせ先・リンクはテスト用です。
- 問い合わせボタンは仮のメールアドレスです。公開前に必ず変更してください。
- Google Fontsを読み込むため、ネット接続時はフォント表示に外部通信を使用します。

## ローカル確認
`index.html` をブラウザで開いてください。

## Cloudflare Pagesへの公開
GitHubにこのフォルダの中身をアップロードし、Cloudflare PagesでGitHubリポジトリを接続します。
ビルドコマンドは不要、出力ディレクトリは `/` または空欄で設定します。
